# 🪲 곤충 로봇 배틀 3D

곤충을 고르고, 로봇 아이템을 붙여서 3D 경기장에서 싸우는 배틀 게임이에요. 휴대폰·태블릿 터치와 키보드 모두 돼요.

- 곤충 로봇, 붙인 아이템, 경기장(풀숲·꽃밭·고철 공장·밤의 숲)이 모두 3D로 그려져요. 카메라가 두 로봇을 따라 움직이며 가까워지면 확대돼요.
- 3D 그래픽은 [three.js](https://threejs.org) (MIT 라이선스)로 만들었고, `index.html` 안에 함께 들어 있어서 파일 하나로 실행돼요.

- **실행 (노트북)**: `index.html` 파일 하나를 크롬에서 더블클릭. Node.js도, 다른 파일도 필요 없어요.
- **실행 (휴대폰)**: https://skbroadbandsustainability-create.github.io/gamepark/bug-robot/
  - 휴대폰을 가로로 돌려서 해요. 크롬 메뉴 → "홈 화면에 추가"를 누르면 앱처럼 실행돼요.

가까이 있는 상대 쪽으로 공격이 자동으로 조금 맞춰져요.

## 🤖 메가 로봇 변신
상대를 때릴 때마다(맞을 때도 조금) **로봇 게이지**가 차요. 꽉 차면 "변신! 메가 로봇!" 하면서 12초 동안 메가 로봇이 돼요: 몸이 크고 키가 커지고, 어깨 대포·제트팩·V자 뿔이 생기고, 공격력 1.35배, 받는 피해 0.7배, 더 빠르고 기술 충전이 빨라지며 기술이 한 단계 더 세져요. 컴퓨터 상대도 변신해요.

## ✨ 기술 업그레이드
곤충마다 기술이 두 개 있어요. 조립 화면의 ✨ 기술 탭에서 코인으로 Lv3까지 올려요 (Lv2 120코인, Lv3 260코인). 레벨이 오르면 피해가 세지고 충전이 빨라지고, 개수·범위·시간도 늘어나요.

## 로봇 조립 (아이템 붙이기)
곤충 한 마리에 **머리 · 등 · 다리 · 무기** 자리마다 아이템을 하나씩 붙일 수 있어요. 붙인 아이템은 로봇 모양에 그대로 보이고 능력치가 바뀌어요. 1P 로봇과 2P 로봇을 따로 꾸밀 수 있고, 🎨 색칠도 돼요.

| 자리 | 아이템 |
|---|---|
| 머리 | 📡 레이더 더듬이 (가끔 두 배 피해) · ⛑️ 강철 헬멧 (피해 줄이기) · 👁️ 레이저 눈 (자동 레이저) |
| 등 | 🚀 로켓 부스터 (빠름) · 🔋 배터리 팩 (기술 빨리 충전) · 🔧 수리 로봇팔 (체력 회복) · 🛡️ 강철 등껍질 (체력 +40) |
| 다리 | 🌀 스프링 다리 · 🛞 바퀴 다리 · 🧲 자석 다리 (안 밀려남) · 💨 터보 다리 |
| 무기 | 🔩 드릴 (공격력) · ⚡ 전기 집게 (감전) · 🎯 미사일 발사대 (유도 미사일) · 🔨 로봇 망치 (멀리 날리기) |

처음에는 사슴벌레·장수풍뎅이·개미와 헬멧·로켓·스프링 다리가 있어요. 나머지는 리그를 깨면 선물로 받거나 코인으로 사요. 메뚜기는 꽃밭 경기장 스테이지 5를 깨면 받아요 (280코인으로 살 수도 있어요).

## 놀이
- **리그 모험**: 풀숲 → 꽃밭 → 고철 공장 → 밤의 숲, 12스테이지. 세계마다 마지막에 커다란 👑 보스 로봇이 나와요.
- **둘이서 대전**: 한 기기에서 둘이서. 상대 체력을 0으로 만들거나, 90초가 끝났을 때 체력 비율이 높으면 승리.
- **경기장 아이템**: 떨어진 아이템을 주우면 로봇에 "철컥!" 하고 잠깐 붙어요. 🔋 체력 회복 · ⚙️ 기술 바로 충전 · 🚀 로켓 (10초 빨라짐) · ⚡ 번개 코일 (10초 감전 공격) · 🛡️ 방패 (피해 30 막기).

진행 상황(코인, 곤충, 아이템, 조립)은 기기(브라우저)에 저장돼요.
