# 🌀 팽이 배틀

팽이를 발사해서 부딪쳐 싸우는 3D 대전 게임이에요. 휴대폰 터치용으로 만들었어요.

- **실행 (노트북)**: `public/spin-top/index.html`을 크롬에서 더블클릭. Node.js가 필요 없어요.
  - F12 → 📱 기기 모드 버튼을 켜면 휴대폰 화면과 터치를 흉내 낼 수 있어요.
  - 키보드: 1P = WASD 이동, 스페이스 발사/기술 · 2P = 방향키 이동, 엔터 발사/기술 (꾹 눌렀다 떼면 발사)
- **실행 (휴대폰)**: https://skbroadbandsustainability-create.github.io/gamepark/spin-top/
  - 크롬 메뉴 → "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행되고, 한 번 연 뒤에는 인터넷 없이도 돼요.

## 규칙
- 화면을 당겼다 놓으면 반대쪽으로 발사돼요. 많이 당길수록 세고 오래 돌아요.
- 화면을 누른 채 끌어서 조종하고, 기술 버튼으로 필살기를 써요.
- 부딪칠 때마다 HP가 줄어요. 상대 HP를 0으로 만들면 승리! (90초가 끝나면 남은 HP 비율이 높은 쪽이 승리)
- 회전력이 0이 되면 HP가 계속 줄어요.
- 경기 중에 아이템(하트, 회전 배터리, 파워 별, 방어 큐브, 바람 신발, 기술 충전)이 나타나요.
- 이기면 코인을 받고, 코인으로 팽이를 강화해요 (최대 Lv10).

## 파일
```
index.html            화면과 스타일, 스크립트를 순서대로 불러옴 (모듈/빌드 없음)
libs/three.min.js     Three.js r149 (전역 빌드)
js/data.js            팽이 8종, 특성, 기술, 아이템, 강화, 보상, AI 난이도, 밸런스 수치 ← 수치는 여기서 조절
js/save.js            코인/레벨 저장 (localStorage)
js/battle.js          물리, 충돌 피해, 특성, 기술, 아이템, 승패
js/ai.js              컴퓨터 팽이
js/render.js          3D 경기장, 팽이 모델, 이펙트
js/input.js           터치/마우스/키보드
js/ui.js              메뉴, 선택/강화 화면, 전투 HUD, 결과
js/main.js            게임 루프, 앱 설치(PWA) 연결
manifest.webmanifest, sw.js, icons/   휴대폰 홈 화면 설치와 오프라인 실행
```
